# SubGenerator

Standalone-решение для сборки и проверки VPN-конфигов из подписок. Загружает подписки, проверяет узлы на живучесть, тестирует обход блокировок и формирует итоговую подписку (`subs.txt`), готовую для импорта в Karing, Hiddify, happ, v2rayN.

## Дисклеймер

Проект создан **исключительно в целях тестирования и научного интереса**: изучение поведения сетевых протоколов, фильтрации трафика и устойчивости конфигураций в контролируемой среде.

Автор не призывает и не содействует использованию инструмента в нарушение законов или правил вашего региона. Используйте только в разрешённых целях и только с подписками, на работу с которыми у вас есть право.

---

## Возможности

- GUI и консольный режим (`--cli`).
- Поддержка vless, vmess, trojan, shadowsocks, hysteria, hy2, WARP.
- Парсинг подписок в форматах: plain text, base64, Clash YAML, JSON.
- Дедупликация конфигов (по протоколу, хосту, порту, нормализованному URL).
- TCP/UDP-ping для быстрого отсева мёртвых узлов (до 256 потоков).
- Тестирование через TUN (весь трафик проверок через виртуальный адаптер).
- Проверка Telegram, ChatGPT, Instagram, скорости download/upload.
- DPI-проверки: DPI, DPI-active, Zapret, Resilience.
- Автоматическая генерация WARP-конфигов с разными endpoint:port:MTU.
- Сохранение настроек между запусками.
- Окно результатов с цифрами по каждому этапу.

## Установка

### Сборка из исходников

Требования: Python 3.12+, зависимости из `requirements.txt`.

```bat
pip install -r requirements.txt
python -m ui.main
```

Консольный режим:

```bat
python -m ui.main --cli --help
```

### Сборка exe

```bat
build_release.bat
```

Результат в `build\`:
- `SubGenerator.exe` — GUI (запрашивает права админа автоматически).
- `SubGenerator-CLI.exe` — консольный режим (запрашивает права админа).

## Использование

### 1. Подписки

На странице «📚 Подписки» добавьте URL подписок (по одной на строку). Поддерживаются:
- Прямые ссылки на `.txt`, `.yaml`, `.json`
- Base64-кодированные подписки
- Clash YAML с секцией `proxies:`
- Локальный файл с конфигами (тумблер «Свой файл»)

### 2. Тестирование

На странице «▶ Тестирование» настройте параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| Потоков | 32 | Параллельных проверок (64 для 32GB RAM) |
| Таймаут | 15 сек | На один узел |
| Макс. пинг | 1500 мс | Отсев по задержке |
| Мин. скорость | 3000 КБ/с | Для 1080p видео |
| TUN | Вкл | Тестирование через виртуальный адаптер |

Этапы проверки (выполняются последовательно):

1. **TCP/UDP-ping** — быстрый отсев мёртвых портов (256 потоков).
2. **SOCKS-ping** — проверка работы узла как прокси.
3. **Stress-test** — 3 раунда спидтеста + Telegram.
4. **DPI** — проверка обхода DPI-блокировок.
5. **TUN-check** — полная проверка через TUN (ping, telegram, chatgpt, instagram, speed).
6. **Geo** — определение стран по IP.

### 3. WARP

На странице «🌀 WARP» выберите пресет и DNS:

| Пресет | Конфигов | Для чего |
|---|---|---|
| Авто | 1 | Базовый конфиг |
| 📱 Мобильный | 3 | Порты 2408/500/4500 |
| 🤖 ChatGPT | 2 | WARP+ IP, DNS xbox-dns.ru |
| 🛡️ Максимальный | 6 | Все ключевые порты |
| 🚀 Полный | 16 | 4 IP × 4 порта, разный MTU |

DNS:
- **Cloudflare** (1.1.1.1) — стандартный, быстрый.
- **xbox-dns.ru** (111.88.96.50) — разблокировка ChatGPT, OpenAI, Discord.
- **Свой** — любой DNS.

WARP добавляется в конец `subs.txt` как fallback.

### 4. Перепроверка

На странице «🔁 Перепроверка» можно запустить проверку с любого этапа, не повторяя пинг и стресс-тест. Использует сохранённые рабочие конфиги из `data/.runtime_cache/`.

### 5. Результаты

После прогона открывается окно с цифрами:
- Найдено / рабочих / отбраковано / экспортировано
- По каждому этапу: X/Y прошли


## CLI

```bat
SubGenerator-CLI.exe --workers 32 --timeout 15 --tun-check --add-warp --warp-preset 4
```

Основные параметры:

| Параметр | Описание |
|---|---|
| `--workers N` | Потоков (32 по умолчанию) |
| `--timeout N` | Таймаут на узел, сек |
| `--tun-check` | Тестировать через TUN |
| `--add-warp` | Добавить WARP в подписку |
| `--warp-preset N` | Пресет WARP (0-4) |
| `--warp-dns DNS` | Кастомный DNS для WARP |
| `--dpi-check` | DPI-проверка |
| `--zapret-check` | Zapret-проверка |
| `--no-stress` | Без спидтеста |
| `--start-stage STAGE` | Перепроверка с этапа |

Полный список: `SubGenerator-CLI.exe --help`
