# SubGenerator

Инструмент для сборки и проверки конфигураций из списка подписок. Загружает
подписки из локального файла `sources.txt`, собирает URI-конфиги, проверяет их
живучесть и формирует итоговую подписку (`subs.txt`).

## Дисклеймер

Проект создан **исключительно в целях тестирования и научного интереса**:
изучение поведения сетевых протоколов, фильтрации трафика и устойчивости
конфигураций в контролируемой среде.

Автор не призывает и не содействует использованию инструмента в нарушение
законов или правил вашего региона. Используйте только в разрешённых целях и
только с подписками, на работу с которыми у вас есть право.

## Возможности

- GUI на CustomTkinter и консольный режим (`--cli`).
- Чтение списка подписок из `sources.txt` (одна подписка на строку).
- Сбор конфигов, проверка живучести, отсев мусорных подписок.
- Формирование итоговой подписки `subs.txt` рядом с исполняемым файлом.
- Логи, кеш и отчёты хранятся в каталоге `data/`.

## Запуск из исходников

Требования: Python 3.12+, установленные зависимости проекта.

```bat
python -m ui.main
```

Консольный режим:

```bat
python -m ui.main --cli --help
```

## Сборка exe

```bat
build_release.bat
```

Результат сборки:

- `build\SubGenerator.exe` — GUI.
- `build\SubGenerator-CLI.exe` — консольный режим.

## Файл подписок `sources.txt`

При запуске приложение создаёт пустой `sources.txt` рядом с exe (или в корне
проекта при запуске из исходников), если файла нет. В `sources.txt` указываются
URL подписок — по одному на строку. Пустые строки и строки, начинающиеся с `#`,
игнорируются.

`sources.txt` — локальный пользовательский файл: он не хранится в git и
создаётся автоматически.

## Принцип работы

1. Приложение читает подписки из `sources.txt`.
2. Загружает конфиги из каждой подписки.
3. Проверяет узлы на живучесть.
4. Отсеивает нерабочие подписки.
5. Собирает результат в `subs.txt`.
