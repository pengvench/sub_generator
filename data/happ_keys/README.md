# happ://cryptN/ — ключи расшифровки

Сюда кладётся `pkcs1_keys.json` — приватные RSA-ключи (PKCS#1, DER, base64)
для расшифровки зашифрованных happ-подписок (формат Hiddify).

## Формат файла

```json
[
  "<base64 DER приватного ключа для happ://crypt/...>",
  "<base64 DER приватного ключа для happ://crypt2/...>",
  "<base64 DER приватного ключа для happ://crypt3/...>",
  "<base64 DER приватного ключа для happ://crypt4/...>"
]
```

Порядок строгий: индекс массива соответствует версии ссылки
(`crypt` → 0, `crypt2` → 1, `crypt3` → 2, `crypt4` → 3).
Если какой-то версии нет — ключей в массиве просто меньше; ссылки
этой версии расшифровать не удастся (источник будет помечен ошибкой).

## Где взять ключи

Ключи выдаёт владелец happ-подписки (тот, кто сгенерировал ссылку).
Публичные ключи Happ-проекта можно найти в репозитории
https://github.com/Happ-proxy/happ — приватные части для публичных
схем (если использовалась схема с приватным ключом на стороне
клиента) туда же входят.

## Безопасность

- `pkcs1_keys.json` — СЕКРЕТ. Каталог `data/` игнорируется git;
  файл не попадает в репозиторий и не бандлится в exe.
- Для собранного exe ключи кладутся рядом: `<путь к SubGenerator.exe>/data/happ_keys/pkcs1_keys.json`.

## Зависимость

Расшифровка требует `pip install cryptography`. Библиотека опциональна:
без неё и без happ-источников проект работает как обычно; happ-ссылка
даст внятную ошибку в логе конвейера.
