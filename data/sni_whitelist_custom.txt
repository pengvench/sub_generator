#
# Сюда кладите SNI домены, которые ВЫ ПРОВЕРИЛИ на своей мобильной сети РФ
# и которые РАБОТАЮТ. Они автоматически добавятся к community whitelist
# (data/sni_whitelist.txt, который sync качает из hxehex upstream) + к
# встроенному WHITE_SNI_DOMAINS в python/checkers/sni_category.py.
#
# ВАЖНО: этот файл НЕ перезаливается scripts/sync_sni_whitelist.py —
# только data/sni_whitelist.txt (community) перезаливается.
# Ваши дополнения здесь ПЕРЕЖИВУТ каждый sync.
#
# Формат: по одной строке на домен (можно с или без www.).
# Строки, начинающиеся с '#', игнорируются. Пустые строки тоже.
